16 Nov 2026. Branch `chris/119-cooling-emitters`, commits 751a764..59b3125 (P0–P4). Docs only: no engine code was changed by this review. The builder answers in `05_review_response.md`.

**What was run here:** the v2 suites (`src/thermal`, `src/sim2/run`: 311 pass, 2 skip, the two that need the anchor EPW); a byte comparison against main (e0f4a79); six mutations of the new solver code; the cooled room's EnergyPlus attribution, re-run; the catalogue's 26 rows against a fresh read of the Stelrad PDF. **Not run here:** anything on Bridgewater. ## Verdict

The cooling limit is built correctly and mirrors 108 faithfully. Rule 8 holds byte for byte. Closure is real and enforced. Every catalogue figure matches the source. No tuning.

Two things in P2's write-up need fixing before close:

- The mechanism given for the failed line is wrong. The cooled room's referee already has inside convection matched (F1).
- The gate was widened from the brief's in the same commit as the results. Under the brief's own gate a second line fails (F2).

The numbers behind the attribution are genuine: I reproduced them.
